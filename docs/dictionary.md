# 辞書

辞書に言葉を登録しておくと、HibiVo はその言葉を正しい表記で入力します。社名・製品名・専門用語・人名など、音声認識が苦手な言葉に使います。

辞書は メインウィンドウ › 辞書 で開きます。

## 辞書の働き

登録した言葉は、入力までの 3 か所で使われます。

1. **音声認識のヒント**: 正しい表記（Soniox では読みも）を音声認識（STT）に渡し、その言葉として聞き取りやすくします。
2. **置き換え**: 文字起こしの中に読みや別名が出てきたら、正しい表記に置き換えます。AI 整形をオフにしていても働きます。
3. **AI 整形**: 辞書を AI に渡し、文脈に合わせて正しい表記を使ってもらいます。

ミーティングの文字起こしと議事録にも同じ辞書が使われます。

## 手動で登録する

「言葉を追加」に入力して「追加」を押します（Return でも追加できます）。

| 欄 | 入れるもの | 例 |
|---|---|---|
| 正しい表記 | 入力してほしい書き方 | `AppSync` |
| 読み | その言葉の読み方（ひらがなかカタカナ） | `アップシンク` |
| 別名 | ほかに誤認識されやすい書き方。`,` か `、` で区切って複数入れられます | `アップ シンク, App Sink` |

- ひらがなとカタカナ、全角と半角は区別しません。読みを「ひびぼ」と登録すれば、「ヒビボ」「ﾋﾋﾞﾎﾞ」も置き換えます。
- 英字と仮名の間の空白は、あってもなくても同じに扱います（「AWS ラムダ」と「AWSラムダ」）。
- **2 文字以下の仮名の読み**（「あい」→ AI など）は、ふつうの言葉と取り違えやすいため、自動では置き換えません。AI 整形が文脈から判断したときだけ、正しい表記にします。

## 直した言葉を自動で登録する

音声入力の直後に、誤認識された言葉を自分で書き直すと、HibiVo がそれに気づいて辞書に登録します。

例: 「アップシンクの設定を確認します」と入力されたので、「アップシンク」を「AppSync」に直す → 辞書に「AppSync（読み: アップシンク）」が登録される。

### 登録されたときの表示

画面の下に「辞書に追加しました」というカードが 10 秒ほど表示されます。

- カードをクリックすると、その登録を取り消します。
- ポインタを重ねている間は消えません。読んでから判断できます。
- 見逃した場合や後から取り消したい場合は、辞書の画面から削除できます（下の「辞書を整理する」を参照）。

### 登録される言葉

誤認識を直したと判断できる場合だけ登録します。次のような直し方では登録しません。

- 文章の書き直し（言い回しや内容を変えた、何か所もまとめて変えた）
- 内容の変更（「明日」→「今日」のように、音の似ていない言葉への変更）
- 数字、句読点、助詞、送り仮名だけの変更
- ひらがなとカタカナの違いなど、表記だけの変更
- 2 文字以下の仮名
- **名詞以外の言葉**（「早く」→「速く」のような動詞・形容詞）。「校正する」のような「〜する」の形の名詞は登録します。

漢字の誤変換（「構成」→「校正」など）は「読み」ではなく「別名」として登録します。

すでに登録されている表記を直した場合は、新しい項目を作らず、その項目の別名に追加します。ほかの項目の読みや別名と重なる場合は登録しません。

### 見守る範囲と期間

貼り付けたあと、入力欄のうち HibiVo が入力した部分だけを見守ります。次のどれかが起きたら終わります。

- 別の入力欄やアプリに移った
- 入力欄が空になった
- 次の音声入力を始めた
- 45 秒たった

### 対応していないアプリ

入力欄の内容は macOS のアクセシビリティ機能で読み取ります。ターミナルなど、内容を読み取れないアプリでは自動では登録されません。その場合は **履歴** から登録できます。

1. 履歴で該当する入力を選び、「修正」を押す
2. 誤認識された言葉を直して「保存」
3. 「辞書に追加」に出てきた候補のボタンを押す

### オフにする

辞書 › 自動で追加 ›「入力後に直した言葉を辞書に追加する」をオフにすると、自動では登録しません。

## 辞書を整理する

一覧の各行は 1 つの言葉です。

| 表示 | 意味 |
|---|---|
| ✨ のアイコン | 直した言葉から自動で登録された言葉 |
| I 字のアイコン | 手動で登録した言葉 |
| 行の右のスイッチ | オフにすると、項目を残したまま使わなくなります |
| 鉛筆のボタン（ポインタを重ねると表示） | 表記・読み・別名を編集します。行のダブルクリックでも開きます |
| ゴミ箱のボタン（ポインタを重ねると表示） | 削除します。取り消しはできません |

- 上の「すべて / 手動 / 自動 / 無効」で絞り込み、右の検索欄で表記や読みから探せます。
- 自動で登録された言葉を見直したいときは「自動」で絞り込むと便利です。
- この機能が入る前に登録した言葉は、すべて「手動」と表示されます。
- 無効にした言葉は使われませんが、同じ言葉が自動で登録し直されることもありません。

## プライバシー

- 辞書は `~/Library/Application Support/HibiVo/vocabulary.json` に保存します。
- 自動登録のために読み取った入力欄の内容は、保存も送信もしません。辞書に登録するのは、直した言葉とその元の書き方だけです。
- 辞書の内容は、音声認識のヒントと AI 整形のために、設定している STT Provider と LLM Provider に送られます。
